Import

Uploads one or more wordlists from this browser into the currently selected database, one at a time (each file is imported before the next is uploaded). You can pick more files while an upload is running; they are added to the queue for the same database. Reads of that database are refused while it is importing. Duplicates are removed automatically. The browser upload imports every line (no length filter).
